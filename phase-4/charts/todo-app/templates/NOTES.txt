## Accessing the Application

{{- if .Values.ingress.enabled }}
The application is accessible via ingress:

{{- range .Values.ingress.hosts }}
  http://{{ .host }}
{{- end }}

Add the following to your /etc/hosts file:
  $(minikube ip) {{ (index .Values.ingress.hosts 0).host }}
{{- else }}
To access the application, run:

  kubectl port-forward svc/{{ .Release.Name }}-frontend-service 3000:3000 -n {{ .Release.Namespace }}

Then open: http://localhost:3000
{{- end }}

## Useful Commands

Check pod status:
  kubectl get pods -n {{ .Release.Namespace }}

View logs:
  kubectl logs -l app=todo-backend -n {{ .Release.Namespace }}
  kubectl logs -l app=todo-frontend -n {{ .Release.Namespace }}

Scale backend:
  kubectl scale deployment {{ .Release.Name }}-backend --replicas=3 -n {{ .Release.Namespace }}

Upgrade release:
  helm upgrade {{ .Release.Name }} ./charts/todo-app -n {{ .Release.Namespace }}

Uninstall:
